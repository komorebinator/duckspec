# Duplicate root file in grep results

`grep` stops reporting the project's root file twice.

## What changed, and why

**`grep` returns one row per matching file again.** 0.10.1 prepended the root project file to the
term walk in order to search it. The walk already yields the root, so the only effect was a second,
identical row for every match found there — and matches there are common, since the root holds
`goals`, `settings`, `uses`, `guidelines` and `ai_instructions`. The prepend is removed;
`resolver#grep_terms` is byte-identical to 0.10.0 again, which is also what its specification has
described throughout.

The entry for 0.10.1 has been corrected: it presented this regression as a new capability.
